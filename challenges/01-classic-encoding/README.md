# 01 · 编码与古典密码识别

**方向**：密码安全（古典密码）　**难度**：入门　**分值**：10

## 背景
口令、密钥、提示常被人用各种编码或古典密码“随手一藏”。网络安全工作里第一步往往是**认出它是什么**，再还原内容。

## 题面
`samples.txt` 里有 10 个样本，每行一个。请判断每个样本的编码/加密类型，并还原出明文。

## 提交格式
每条写成 `编号-类型-明文`，例如：
```
1-Base64-hello
```
其中维吉尼亚密钥为 `KEY`，栅栏为 2 栏，凯撒位移需自己试出。

## 提示
- 先看**字符集**：只有 `0-9a-f` 且长度为偶数 → Hex；全大写加 `2-7` → Base32；出现 `%XX` → URL 编码；只有点划 → 摩斯；只有 A/B 且 5 个一组 → 培根。
- 多层编码很常见：解一层后重新判断。
- 工具：CyberChef 离线版（Magic 功能）、`tools/` 里的脚本、或纸笔。

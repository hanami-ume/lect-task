# 04 · 流量中的明文敏感数据

**方向**：数据安全（敏感数据识别 / 明文传输）　**难度**：入门　**分值**：15
**对应真题**：2025 决赛运维实操第 6 题

## 背景
`api_traffic.pcap` 是某寄递业务系统被抓到的一段 HTTP 流量（明文未加密）。攻击队报告：某接口直接返回了**明文**的身份证号和手机号。

## 题面
1. 找出泄露明文身份证号和手机号的接口 URL（不含 `?` 后的参数），格式 `/xxx/xxx/xxx`。
2. 给出该响应所在的帧号，以及泄露的字段名。
3. 流量里还有一个 18 位数字字段，它是身份证号吗？说明判断依据。
4. 同名接口有另一个版本做了脱敏，写出它的路径，并说明为什么整改后仍要下线旧版本。

## 提交格式
```
路径,响应帧号,泄露字段;整改版本路径
```

## 提示
- Wireshark：过滤 `http` → 统计 → HTTP → 请求；或 编辑 → 查找分组 → 字符串 搜 `cert_no` / `mobile`。
- 没有 Wireshark：`python3 pcap_summary.py api_traffic.pcap`
- 18 位数字要用身份证规则（日期 + 校验位）判断真假；带 `****` 的字段不算明文泄露。

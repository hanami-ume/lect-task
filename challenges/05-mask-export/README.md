# 05 · 脱敏导出与文件指纹

**方向**：数据安全（个人信息脱敏 / 数据共享）　**难度**：进阶　**分值**：20
**对应真题**：2025 决赛综合防御 域控部分第 13、14 题

## 背景
一批寄件人数据要共享给第三方做测试，共享前必须按《个人信息数据安全规范》剔除不合规记录并脱敏。

## 题面
按 `policy.txt` 的规则：
1. 找出不合规记录，写出被剔除的 id（数值升序，下划线连接，如 `1_2_3`）。
2. 脱敏并导出 `cleaned.csv`，计算其 **32 位小写 MD5**。
3. 说明：为什么两个“看起来一样”的 CSV，MD5 可能不同？至少说 3 个原因。
4. 说明：脱敏后的数据属于“去标识化”还是“匿名化”？为什么？

## 提交格式
```
被剔除id;cleaned.csv的MD5
```

## 提示
- **先校验后脱敏**：脱敏后号码被遮住，就无法再判断是否合规。
- 身份证要同时查：17位数字+1位校验、第7~14位是合法日期、第18位校验码正确；手机号第二位必须 3~9。
- 导出严格按规则：UTF-8 无 BOM、CRLF 换行、末尾不留空行。
- `mask_template.py` 里有 3 处 TODO 待补全。
- `certutil -hashfile cleaned.csv MD5`（Windows）/ `md5sum cleaned.csv`（Linux）。

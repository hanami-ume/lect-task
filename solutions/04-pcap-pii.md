# 题解 · 04 流量中的明文敏感数据

## 答案
- 泄露接口：**`/api/v1/sender/detail`**
- 响应帧 **46**（对应请求帧 44）；泄露字段：`mobile` = `13812345678`、`cert_no` = `99000019880312541X`（还含明文 `name`、`address`）。
- `/api/v1/order/list` 里的 `order_id` `202611050000000123` 是 18 位数字，但第 7~14 位 `05000000` 不是合法日期、校验位也不对，**不是身份证号**。
- 已整改版本：**`/api/v2/sender/detail`**（字段已掩码）。旧版本只要还能访问就仍在泄露，整改后必须下线或同样脱敏。

## 思路
```
# Wireshark
过滤 http → 统计/HTTP/请求 列出所有 URL
编辑→查找分组→字符串 搜 cert_no / mobile / 身份证
右键→追踪流→HTTP流 把响应对回请求，读请求行里的路径

# 无 Wireshark
python3 pcap_summary.py api_traffic.pcap
```
`pcap_summary.py` 会标出疑似明文手机号和 18 位数字串，并校验身份证校验位。

## 知识点
- 明文 HTTP 下，URL、参数、Token、响应体全部可见；敏感数据接口即使在内网也应走 HTTPS/TLCP，并对字段脱敏。
- 判断“是不是身份证号”要用格式规则（日期 + 校验位），不能只看“18 位数字”。
